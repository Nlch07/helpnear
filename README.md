# 🤝 helpnear

**Выполнили студены ИВТ 4 курс**

Это приложение создано для того, чтобы связать тех, кому нужна поддержка (сопровождение, помощь по дому, доставка лекарств), с волонтерами, готовыми помочь. Мы стремимся сделать городскую среду доступнее, а процесс поиска помощи — быстрым и безопасным.
